# Battery Time 1.0.0

一个简单的原生 macOS 菜单栏电池时间工具。仅支持 Apple Silicon（M 系列），需要 macOS 13 或更新版本。

- 菜单栏显示电池图标与系统估算时间；低电量使用黄色或红色，接电显示插头。
- 原生菜单显示电池剩余电量和剩余时间；充电时明确显示距离充满的时间。
- 设置仅有中文 / English 和开机自启动。
- 灰色电池时钟图标；无联网、无统计、无第三方运行依赖。
- MIT 开源。

下载 `Battery-Time-1.0.0-arm64.dmg`，打开后把 Battery Time 拖进 Applications。

**此版本使用 ad hoc 签名，尚未经过 Apple Developer ID 签名或公证。** 首次打开可能被 macOS 拦截；确认信任来源后，可在“系统设置 → 隐私与安全性”中选择“仍要打开”，也可以从源码自行构建。

已验证：15 项核心测试、Release 构建、arm64 架构与签名完整性、DMG 校验、中英文切换、登录启动的注册与取消。剩余时间由 macOS 提供，会随负载变化；系统暂时没有估算时显示“估算中”。

---

A small native battery-time menu bar app for Apple Silicon Macs running macOS 13 or later. Two settings only: Chinese / English and launch at login. No networking or analytics. MIT licensed.

Download the DMG and drag **Battery Time** into **Applications**. This build is **ad hoc signed and not notarized**. If macOS blocks the first launch, use **System Settings → Privacy & Security → Open Anyway** only after verifying that you trust the download, or build from source.

The release includes `SHA256SUMS.txt` for download verification.
