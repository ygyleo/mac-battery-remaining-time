# Battery Time 1.1.0

- 电池图标改为接近原生的实心圆角形态，充电、接电时均保留当前电量填充。
- 正在充电显示闪电，接电但未充电显示插头。
- 点击菜单缩窄为两行数据，移除“设置”和“退出”，文字保持正常可读颜色。
- 从 Spotlight 或 Finder 打开 App 时显示设置；关闭设置后继续驻留菜单栏。开机自启动不会弹出设置。
- 新增“在菜单栏显示剩余时间”开关，默认开启并保存选择。设置共三项：语言、菜单栏时间显示、开机自启动。

仅支持 Apple Silicon（M 系列），需要 macOS 13 或更新版本。下载 `Battery-Time-1.1.0-arm64.dmg`，将 **Battery Time** 拖入 **Applications**。升级时先退出旧版，再替换应用，已有偏好会保留。需要退出后台时，打开设置窗口并按 **⌘Q**，或使用应用菜单中的“退出 Battery Time”。

**此版本仍采用 ad hoc 签名，尚未经过 Apple 公证。** 首次打开若被 macOS 拦截，确认信任来源后，可在“系统设置 → 隐私与安全性”选择“仍要打开”，或从源码自行构建。安装包附有 `SHA256SUMS.txt`。

---

- Filled, rounded battery icon with charge level preserved while charging or connected.
- Lightning bolt while charging; plug when connected without charging.
- Compact two-row status menu with readable text and no Settings or Quit buttons.
- Opening the app from Finder or Spotlight shows Settings. Closing Settings keeps the app in the menu bar; login launches stay quiet.
- New **Show time in menu bar** setting, enabled by default and remembered.

For Apple Silicon Macs on macOS 13 or later. Download the DMG and drag **Battery Time** into **Applications**. To update, quit the old app and replace it with the new copy. Preferences are retained. Open Settings and press **⌘Q** to quit the app completely.

This release is **ad hoc signed and not notarized by Apple**. If macOS blocks the first launch, use **System Settings → Privacy & Security → Open Anyway** only after verifying that you trust the download, or build from source. A SHA-256 checksum file is included.
