# Battery Time 1.2.0

- 新增“立即充满”：系统确认优化充电暂停，或达到手动充电上限时显示；点击后重新检查状态并发送一次原生充电请求。
- 普通菜单仍为两行数据，设置仍为三项。保留已确认的白色黑边闪电和插头、电量填充及状态刷新。
- 该功能使用运行时检查的私有 PowerUI 接口，不支持或查询失败时隐藏。手动上限需要 macOS 26.4+；部分系统在原生操作后会将上限保留为 100%，应用会在操作前提示，且不会自动恢复上限。

下载 `Battery-Time-1.2.0-arm64.dmg`。Apple Silicon、macOS 13+。ad hoc 签名，尚未经过 Apple 公证。

- Adds Charge to Full Now when macOS reports an overridable optimized-charging pause or a reached manual charge limit. Rechecks state and sends one native request per action.

- Uses runtime-checked private PowerUI methods; unavailable or unreadable interfaces hide the action. Manual limits require macOS 26.4+. Some versions leave the limit at 100% after the native action; the app explains this before requesting it and does not restore limits automatically.
